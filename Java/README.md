# Java

A complete, ordered walk through Java — from what actually happens when you type `java`
to virtual threads, the JVM memory model, and the patterns used in production codebases.

**Target version: Java 21 (LTS).** Everything here runs on 21 or newer. Where a feature
is newer than Java 8, the lesson says so explicitly and shows the older equivalent, so
this material is still useful if your workplace is on Java 8, 11 or 17.

---

## How to run these files

Install a JDK (21+) from [Adoptium Temurin](https://adoptium.net/), then confirm:

```bash
java -version
```

Every lesson is a **single self-contained file** with its own `main` method. Since Java 11
you can run a `.java` file directly, with no compile step and no project setup:

```bash
java Java/01-getting-started/01-introduction-and-how-java-runs.java
```

That single command is all you ever need for this stack. If you prefer the classic
two-step, or want to inspect the generated bytecode:

```bash
javac -d out Java/01-getting-started/02-your-first-program.java
```

```bash
java -cp out FirstProgram
```

> The classes in these files are deliberately **package-private** (no `public` keyword),
> which is what allows the numbered, hyphenated filenames to compile with `javac`
> without the usual "class name must match file name" error.

A handful of later lessons (JDBC, JUnit, Maven/Gradle) need extra software. Each of those
lessons lists exactly what to install at the top of its `.md`, and every one has a
zero-install alternative so you are never blocked.

| A week | 01–20. You can write real programs. |

interview questions and most real bugs live.
